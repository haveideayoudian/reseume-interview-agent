## 上午：项目启动

### 1. 项目方向确定
- **项目**：面试简历优化 Agent MVP
- **核心功能**：
  1. 用户上传 JD + 简历
  2. Agent 评估匹配度，指出短板
  3. 按 STAR 原则润色优化简历项目描述
- **目标用户**：技术路线（算法/后端）+ 职能路线（供应链/产品）
- **部署计划**：先自用，成熟后转 To C 产品

### 2. 技术选型确认
- **框架**：Deep Agents (基于 LangChain + LangGraph)
- **LLM**：OpenAI (GPT-4o)
- **输入方式**：文件上传 (PDF/Word/TXT) + 粘贴文本
- **输出方式**：纯对话式
- **流水线**：部分并行（JD 解析 + 简历解析并行，后 3 步串行）

### 3. 评估标准确定
- **匹配度评估**：语义匹配 + 量化评分 (0-100)
  - 90-100: 优秀
  - 70-89: 良好
  - 50-69: 一般
  - 0-49: 较差
- **文字质量评估**：三维度
  - 语法：错别字、语法错误
  - 专业性：行业术语准确性
  - 清晰度：表达简洁性
